## 画面一覧
| # | 画面 | 説明 |
|---|---|---|
| 01 | 投稿一覧（トップ） | 写真を3列×4行で表示（1ページ12件）。写真に料理名とお気に入り（♡）を重ねる |
| 02 | 投稿詳細 | 写真・料理名・カロリー・食べた日・ユーザー名・メモ・材料・作り方。編集・削除は自分の投稿のみ |
| 03 | 投稿作成 | 写真・料理名・カロリー・食べた日は必須。エラー表示と保存中の表示あり |
| 04 | 投稿編集 | 作成画面と同じ項目。元のデータが入った状態で表示 |
| 05 | マイページ | 日付で絞り込み、その日の合計カロリーを表示 |
| 06 | お気に入り一覧 | お気に入りにした投稿を一覧と同じ形で表示 |

※ ログイン・会員登録画面は Breeze の画面を使うため、ワイヤーフレームは作成していません
