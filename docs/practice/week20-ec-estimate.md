## 内訳

| 項目 | 含まれる作業 |
|---|---|
| 要件定義 | お客さん・お店の管理者のユーザーストーリーと機能の整理 |
| 画面設計 | お客さん用の画面と管理画面のワイヤーフレーム・画面遷移図 |
| DB設計 | 商品・カテゴリ・カート・注文などのテーブル定義・ER図 |

- 決済サービス（Stripe）の手数料、メール配信サービスの利用料、サーバー費用は含まない
- 納期は、1スプリント2週間×3回（約6週間）とした
- リスク対応費は、実装（64時間）の25%とした
