# ECサイトのユーザーストーリー

## 買い物をするユーザー
1. 買い物をするユーザーとして、住所や支払い方法を登録してログインしたい。なぜなら、注文のたびに毎回入力するのは面倒だから。
2. 買い物をするユーザーとして、商品をキーワードで探したい。なぜなら、欲しいものをすぐ見つけたいから。
3. 買い物をするユーザーとして、商品をジャンルごとに見たい。なぜなら、似た商品を比べて選びたいから。
4. 買い物をするユーザーとして、商品の詳細を見たい。なぜなら、写真や説明がないと、実際に届くものが想像できないから。
5. 買い物をするユーザーとして、気になる商品をお気に入りに登録したい。なぜなら、あとから見返して買うかどうか判断したいから。
6. 買い物をするユーザーとして、ほかの人のレビューを見たい。なぜなら、買うかどうかの参考にしたいから。
7. 買い物をするユーザーとして、欲しい商品をカートに入れたい。なぜなら、複数の商品をまとめて注文したいから。
8. 買い物をするユーザーとして、カートの商品をサイト上でそのまま支払いたい。なぜなら、お店に行ったり振り込みに行ったりせずに買い物を終えたいから。
9. 買い物をするユーザーとして、注文後に確認メールを受け取りたい。なぜなら、注文がきちんと完了したか不安になるから。
10. 買い物をするユーザーとして、注文履歴を見たい。なぜなら、以前に買ってよかったものをもう一度買いたいから。

## お店の管理者
1. お店の管理者として、商品ページを作成・編集したい。なぜなら、お客さんに商品の詳細を確認してもらい、売上につなげたいから。
2. お店の管理者として、商品のカテゴリを管理したい。なぜなら、商品がバラバラに並ぶと、お客さんが探しにくくなるから。
3. お店の管理者として、商品の在庫数を管理したい。なぜなら、売り切れの商品を注文されないようにしたいから。
4. お店の管理者として、入った注文を確認して発送済みにしたい。なぜなら、どの注文の発送が終わっているかをはっきりさせたいから。
5. お店の管理者として、お客さんが配送状況を自分で確認できるようにしたい。なぜなら、問い合わせに一人ひとり答えるのは大変だから。
6. お店の管理者として、返品・キャンセルに対応したい。なぜなら、欠陥品などがあったときに回収して返金したいから。
7. お店の管理者として、割引クーポンを発行したい。なぜなら、定期的に割引をして、もっと買ってもらいたいから。
8. お店の管理者として、売上を確認したい。なぜなら、よく売れる商品を中心に販売したいから。
9. お店の管理者として、不適切なレビューを非表示・削除したい。なぜなら、ほかのお客さんが嫌な思いをしないようにしたいから。
10. お店の管理者として、問題のある会員を利用停止にしたい。なぜなら、ほかのお客さんやお店を守りたいから。
