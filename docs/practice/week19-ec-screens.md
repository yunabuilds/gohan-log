# 練習課題1：ECサイトの画面設計（Figma）

## Figma の URL
https://www.figma.com/design/QFEhzr2fOLEm43iqyESQJr/week19-practice-ec?node-id=0-1&t=hY2iOAX0EjNEbXsV-1

## 画面一覧
| # | 画面 | 主な要素 |
|---|---|---|
| 01 | トップ | セール中バナー、カテゴリー（服・化粧品・食品・雑貨）、あなたへのおすすめ、売上ランキング |
| 02 | 商品一覧 | カテゴリー名と件数、並び替え・絞り込み、商品（写真・商品名・価格）を3列で表示、ページネーション |
| 03 | 商品詳細 | 商品写真、価格（税込み）、サイズ選択、数量、カートに入れるボタン、評価と件数、商品説明 |

## 画面の流れ
トップ →（カテゴリーを押す）→ 商品一覧 →（商品を押す）→ 商品詳細 →（カートに入れる）

## 工夫した点
- 一番押してほしい「カートに入れる」ボタンを赤色で目立たせた
- サイズはボタンで選べるようにし、入力の手間を減らした
- トップにランキングとおすすめを置き、商品を探さなくても選べるようにした
