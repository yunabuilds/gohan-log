# 要件整理の練習

曖昧な要求を、作れる形（数字・範囲・誰が）に書き直す。

| 曖昧な要求 | 何が曖昧か | 明確な要件 |
|---|---|---|
| 「サイトを速くしてほしい」 | 何秒なら「速い」のか決まっていない | 各ページを3秒以内に表示する |
| 「使いやすくしてほしい」 | 何がどうなれば使いやすいのか決まっていない | トップページから、見たい画面に3クリック以内でたどり着ける |
| 「たくさんの人が使えるようにしてほしい」 | 何人が、同時にどれくらい使うのか決まっていない | 同時に100人がアクセスしても、各ページを3秒以内に表示する（人数はヒアリング結果をもとにする） |
| 「スマホでも見られるようにしてほしい」 | どの機種・どのブラウザで、どこまで使えればいいのか決まっていない | iPhone（Safari）と Android（Chrome）の最新版で、横スクロールせずに全画面を表示・操作できる |
| 「ダブルブッキングをなくしたい」 | システムが何をすれば防げるのか決まっていない | 同じ担当者の同じ時間帯を選択しようとしたら、エラーを表示して登録できないようにする |

## 学んだこと
- 明確な要件にするには、数字や名前を入れて「できた／できていない」を確かめられる形にする
- 明確な要件の範囲（規模）は広くしすぎない
- 数字は自分で決めず、ヒアリングで聞いた事実をもとに決める
