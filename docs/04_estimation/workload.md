# 工数見積もり

1ポイント＝約1時間として見積もる。
Breeze やブログアプリで経験済みの作業は少なめ、初めての作業は多めに見積もった。

## 機能別工数表
| 作業 | 要件ID | 優先度 | ポイント（時間） | 備考 |
|---|---|---|---|---|
| 環境構築（src/ に Laravel・Docker・Breeze） | - | Must | 3 | ブログアプリの Docker 設定を流用 |
| 会員登録・ログイン・ログアウト | F-01 | Must | 1 | Breeze を使い、ログイン後の移動先だけ変える |
| DB・モデル・リレーション | - | Must | 2 | posts・favorites のマイグレーション、モデル、テストデータ |
| 投稿作成・画像アップロード | F-02 | Must | 3 | バリデーション、storage への保存 |
| 投稿一覧（写真グリッド・ページネーション）・詳細 | F-03 | Must | 3 | 3列×4行のレイアウト |
| 投稿の編集・削除 | F-05・F-06 | Must | 2 | 画像の差し替え・削除を含む |
| 権限管理（Policy） | F-07 | Must | 1 | ブログアプリと同じ形 |
| お気に入り（Ajax）・お気に入り一覧 | F-04 | Must | 4 | 初めて作る部分が多いので多めに見積もる |
| マイページ（日付で絞り込み） | F-08 | Must | 2 | |
| 1日の合計カロリー | F-09 | Should | 1 | マイページに追加 |
| レシピ（材料・作り方） | F-10 | Should | 1 | 投稿フォームに項目を追加 |
| 見た目の調整（スマホ対応） | - | Must | 2 | |
| 自動テスト（PHPUnit） | - | Must | 3 | 主要な機能 |
| デプロイ（EC2・RDS の再開、本番設定） | - | Must | 3 | |
| **合計** | | | **31** | |

## バッファ
- 想定外のバグ修正・仕様変更・テストとデバッグのため、25% を追加する
- 31時間 × 1.25 ＝ **約39時間**

## 使える時間との比較
- 実装期間：10月26日〜31日の6日間
- 1日約6〜7時間 × 6日 ＝ 36〜42時間
- 見積もり39時間とほぼ同じで、**余裕は少ない**

## 間に合わないときの判断
1. Should の「1日の合計カロリー」「レシピ（材料・作り方）」を後回しにする（2時間）
2. 見た目の調整は最低限にする
3. Must の機能とデプロイは必ず終わらせる
